CS50's Tideman


A C program that implements the Tideman ranked-choice voting algorithm. Voters rank candidates in order of preference, and the program calculates the winner by constructing a directed graph of candidate preferences, avoiding cycles. The goal is to ensure that the most preferred candidate wins fairly, even in complex voting scenarios. Key concepts used: Graph theory and cycle detection Sorting algorithms to order pairs of candidates 2D arrays and recursion Real-world application of election systems

CS50's Dictionary


A C program that implements a spell checker using a hash table to store words from a dictionary file. The program loads a large dictionary into memory, then checks another text file for misspelled words by comparing each word against the hash table. Efficient memory management and file I/O operations are used throughout the project. This project emphasizes: Data structures: Hash tables and linked lists File handling and parsing text input Custom hash functions and dictionary loading/unloading Performance benchmarking on large datasets
